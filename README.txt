QREVORA CREATIVE WEBSITE
========================

Files:
- index.html       Main website page
- style.css        Colours, layout, responsive design and animations
- script.js        Mobile navigation, portfolio image preview and current year
- assets/          Your two supplied portfolio designs

HOW TO OPEN:
1. Extract the ZIP file.
2. Open the qrevora_creative_website folder.
3. Double-click index.html. It opens in your browser.

CUSTOMIZATION:
- Change text in index.html.
- Change theme colours at the top of style.css under :root.
- Add more portfolio images to assets/ and duplicate a portfolio-item block in index.html.
- Google Fonts require internet; fallback fonts are included.

This is a static website. To publish it online, upload the extracted files to a static hosting service such as GitHub Pages, Netlify or your hosting provider.
